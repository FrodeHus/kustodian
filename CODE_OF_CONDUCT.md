# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and don't harass anyone. Maintainers may edit or remove
contributions, and restrict participation, for behaviour that breaks this code.

## Reporting

Report unacceptable behaviour privately to the maintainer through
[GitHub's report feature](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam) or a
private [security advisory](https://github.com/FrodeHus/kustodian/security/advisories/new) if it concerns this project. All
reports are reviewed and kept confidential.
