Why Kustodian

OData fetches the data.
KQL answers the question.

Graph speaks OData, but $filter works on some properties and not others, and there are no joins or aggregates. You still page through results and parse the JSON yourself. Kustodian sends OData what the server can handle, then runs the rest of your KQL in memory: mv-expand, join, summarize and more.

OData by handpaging, parsing, scripting

GET /applications?$select=appId,displayName,passwordCredentials&$top=999 GET /applications?$skiptoken=… GET /applications?$skiptoken=… $filter on passwordCredentials/endDateTime: not supported → parse the JSON, flatten and compare dates in a script

In KustodianGR

applications | mv-expand cred = passwordCredentials | where todatetime(cred.endDateTime) < now() | summarize expired = count() by displayName → $filter where Graph supports it, the rest in memory

Explain

See every request before it’s sent.

Explain shows exactly what a Graph query will do to your tenant, without sending anything.

  • The requests. Every Graph call, including per-object reads.
  • The $filter. Which parts of your query run server-side and which run locally.
  • The permissions. The scopes a query needs, before you hit a 403.

Completion and errors from each source’s schema, including nested and mv-expanded fields.

Virtualized grid, charts, JSON and diagnostics. Compare two runs. Export to CSV, JSON or Markdown.

Privacy & security

Your tenant.
Your machine.

Kustodian is a desktop app that signs in as you. There is no Kustodian service in the middle, and nothing leaves your machine except calls to Microsoft.

Network
Talks only to Microsoft’s APIs.
Tokens
Cached in the OS keychain (DPAPI, Keychain or libsecret), never written in plain text.
Your data
Settings, saved queries, snippets, history and tabs are local JSON files.
Sign-in
Delegated, with your work account. Use the Azure CLI’s public client, your own app registration, or let Kustodian create one.
Source
MIT licensed. Read it, build it, report a vulnerability.

Get started

Three commands to your first query.

There are no prebuilt releases yet. Build from source on Windows, macOS or Linux.

01 · Install

The toolchain

.NET SDK 10 and Node.js 22. On Linux, also WebKitGTK 4.1 and libsecret.

$ sudo apt-get install \
  libwebkit2gtk-4.1-dev libsecret-1-dev
02 · Clone

The repository

The build embeds the web UI for you; no separate frontend step.

$ git clone https://github.com/FrodeHus/kustodian
$ cd kustodian
03 · Run

And sign in

Sign in with your work account and open your first tab.

$ dotnet run --project src/Kustodian
